A complete software-development methodology for coding agents — built on a library of composable, version-controlled skills and a bootstrap that makes the agent actually use them. It doesn't make the model smarter. It makes the model disciplined.

When you start building something, a Superpowers-equipped agent doesn't jump straight to code. It steps back and asks what you're really trying to do. It teases a spec out of the conversation, shows it to you in digestible chunks, turns the approved design into a bite-sized plan, and only then writes code — test-first, reviewed task-by-task, verified before it ever claims "done."

It's the bet that what AI coding agents lack isn't capability — it's discipline. And that discipline can be distributed as plain Markdown.

The core loop

Seven skills hand off to each other automatically, forming a closed chain from rough idea to merged code. Each one is a procedure the agent is taught to reach for at exactly the right moment.
